# 触屏操作

[English](CONTROLS.md)

顶部 ⚙ 面板选择 **键盘 / 鼠标** 并开启 **显示触屏按键**。默认使用键盘模式，也可切换 Xbox。视角灵敏度、透明度和大小会保存，且不随渲染分辨率变化。

| 区域或按键 | 操作 |
| --- | --- |
| WASD 滑动区 | 移动，支持斜向 |
| 视角拖动区 | 转动视角 |
| Shift / Ctrl / Space | 奔跑 / 蹲下 / 跳跃 |
| Q / E | 原版左右手绑定 |
| 鼠标左 / 右键 | 原版使用 / 放下绑定 |
| Z / V | 坐下 / 静音绑定 |
| Enter / Esc | 原版确认或聊天 / 返回绑定 |
| ⌨ | 原生文字输入，包含房间名 |

支持多指按住不同控制。切后台、打开设置/文字输入、切换布局时释放已按住的输入。用户已确认移动及按键正常；具体动作仍依游戏当前场景决定。

分辨率可从 ⚙ 或原游戏图形菜单选择，以像素短边定义，长边随窗口比例适配。1.5K 按用户要求为短边 1440；720p 下触控画布也保持原生窗口大小。偏好保存在 Documents/StrayTouchLayout.plist，旧文件名为兼容现有数据而保留。
