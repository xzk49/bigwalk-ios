# Touch controls

[简体中文](CONTROLS.zh-CN.md)

Select **Keyboard / Mouse** in the top ⚙ panel and enable **Show touch buttons**. Keyboard mode is the default, and Xbox remains available. Camera sensitivity, opacity and scale are saved independently of render resolution.

| Area or key | Use |
| --- | --- |
| WASD sliding pad | Move, including diagonal directions |
| Camera drag area | Look around |
| Shift / Ctrl / Space | Run / crouch / jump |
| Q / E | Original left/right-hand bindings |
| Left / right mouse | Original use / release bindings |
| Z / V | Sit / mute bindings |
| Enter / Esc | Original confirm/chat / back bindings |
| ⌨ | Native text entry, including room names |

Multiple fingers may hold different controls. Backgrounding, opening settings/text entry, or switching layouts releases held input. Movement and buttons have user confirmation; individual gameplay actions still follow the game's context.

Choose resolution from ⚙ or the original graphics menu. Presets are defined by the shorter pixel dimension; the longer dimension adapts to the window. 1.5K means a 1440-pixel short edge, as requested. The native touch canvas keeps its own viewport even at 720p. User preferences are stored in Documents/StrayTouchLayout.plist; the historical filename is retained for compatibility.
