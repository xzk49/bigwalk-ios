# BIG WALK iOS

简体中文 · [English](README.md)

将已购买的 **BIG WALK macOS Steam 版**以原生 ARM64 兼容方式运行于 iOS。本仓库提供宿主应用、兼容桥接代码、准备与审计脚本及文档。原版游戏需由使用者通过自己的购买获取；仓库不包含商业游戏二进制、资源、SDK 二进制、签名描述文件、存档或运行时账号数据。

## 已验收版本 — 2026-10-05

固定输入：BIG WALK **1.5.1**、构建 **20260827105422**，Unity **6000.3.17f1**。真机为 **iPhone 17 / A19 / iOS 26.3**。Xcode 最低部署版本为 iOS 17.0；这是构建设置，未代表旧机型已测试。

- 现有地图能进入并正常游玩；游戏声音已有用户实际可听确认。
- 真实 EOS Device ID 登录、连接健康、房间创建、加入码和跨设备地图同步均已验证。认证及网络状态来自真实 SDK 结果，不伪造票据、身份或服务端成功。
- 用户确认触屏键盘布局已显示，移动和按键正常；W、Shift、Ctrl、鼠标左右键还通过了原 Unity 输入按住与松开回读。
- 分辨率为 720p / 900p / 1080p / 1.5K，短边分别为 **720 / 900 / 1080 / 1440 像素**，长边随设备窗口比例计算。原游戏画质菜单及触屏设置均提供四档。
- 关闭全屏后的启动和四档分辨率切换已通过手机真机检查。
- 原 QualitySettings API 的六个桌面整体画质档位均通过测试，启用昂贵变更后恢复原档位。纹理限制始终为 2；同一进程持续运行 90 秒，内存峰值 **2,500,709,264 字节**。用户也确认手动菜单切换正常。

简要状态见 [verification-summary.json](verification-summary.json)，复现步骤见 [BUILD.zh-CN.md](BUILD.zh-CN.md)。

## 实现方式

准备过程只操作独立副本，原 Steam 安装保持只读。提取普通 ARM64 切片并重定向平台及依赖，通过专用兼容框架适配桌面接口，宿主调用原 Unity player 入口。AppKit 窗口及输入桥接至 UIKit，Metal 保持原生渲染；音频桥将桌面 HAL/AudioUnit 调用适配到真实 iOS 音频会话和输出设备。

EOS 适配在固定 GameAssembly 中修改六处受保护的调用范围，使原认证、网络监测和创建/加入菜单路径查询真实 EOS 状态。资源脚本启用 Apple 手柄后端，并使八个原画质预设保留手机已验证的纹理限制。纹理补丁只改变解压 QualitySettings 对象八个字节，其他压缩块保持一致。

720p 下的键盘显示修复将旧桌面逻辑宽度门槛替换为实际 Metal 游戏画布判断；右键修复补齐基类事件处理接口，保留 Unity 原有输入路径。

## 当前限制

实际麦克风收发尚未验收，虽然已观察到 Dissonance 网络握手。可选系统根证书实验未进入已验收版本，完整 HTTPS 证书适配仍待完成。Steam 好友列表和 Game Center 尚未接入，也没有确认 LAN 或离线多人模式。

代码与固定原版哈希绑定，其他游戏版本需要重新审计。仓库不提供 App Store 发行版或通用免签 IPA。安装需使用自己的有效签名、描述文件和可用 entitlement；本地导出的开发签名 IPA 保留原签名设备及有效期限制。
